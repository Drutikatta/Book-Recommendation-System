# 📚 Book Recommendation System

A **Book Recommendation System** built using **Artificial Intelligence and Machine Learning** to recommend books to users based on their interests and preferences.

## 📌 About the Project

With thousands of books available online, finding a book that matches a user's interests can be difficult. This project provides personalized book recommendations by analyzing book information and finding similarities between books.

The system uses **Content-Based Filtering** to recommend books similar to the user's selected or searched book.

## ✨ Features

* 📚 Personalized book recommendations
* 🔍 Search for books
* 🤖 Content-Based Filtering
* 📊 Cosine Similarity for finding similar books
* ⭐ Book ratings and reviews
* 🗂️ Category-wise book listing
* 💬 Users can add reviews
* 📖 Discover similar books based on reading preferences

## 🧠 Recommendation Algorithm

The project uses **Content-Based Filtering** with **Cosine Similarity**.

The recommendation process:

1. Book data is collected and processed.
2. Important features of the books are extracted.
3. Book features are converted into numerical representations.
4. Cosine Similarity is used to measure the similarity between books.
5. Books with the highest similarity scores are recommended to the user.

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Drutikatta/Book-Recommendation-System.git
```

### 2. Navigate to the project folder

```bash
cd Book-Recommendation-System
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

### 5. Open in browser

```text
http://127.0.0.1:5000/
```
